==============================================
 사이트 구조 (architecture)
==============================================

[폴더 구조]

my-site/
├── index.html                    # 메인 틀. 슬롯 3개 + 로더/라우터 연결만 있는 얇은 뼈대
├── architecture.txt              # 이 문서
├── .gitattributes                # Git 설정 파일
├── css/                          # 사이트 전체가 함께 쓰는 디자인 파일
│   ├── base.css                  # 사이트 전체 공통 스타일 + :root 변수
│   └── animations.css            # 재사용 애니메이션 모음
├── js/
│   └── core/                     # 사이트 전체를 움직이는 핵심 기능
│       ├── component-loader.js   # 컴포넌트 자동 불러오기
│       └── page-router.js        # 주소의 #이름 에 맞는 페이지 보여주기
├── components/                   # 화면 조각(기능) 모음. 기능마다 폴더 하나, 안에 html/css/js 한 세트
│   ├── music-player/             # 음악 플레이어 (music-player.html / .css / .js)
│   ├── site-menu/                # 사이트 메뉴 (site-menu.html / .css / .js)
│   └── shooting-stars/           # 별똥별 배경 (shooting-stars.html / .css / .js)
├── pages/                        # 페이지 모음. 페이지마다 폴더 하나
│   └── home/                     # 첫 화면 (home.html)
├── data/                         # 데이터 파일
│   └── playlist.json             # 음악 곡 목록 (경로 + 제목 + 가수)
└── assets/                       # 음악, 이미지 같은 자료 파일
    ├── audio/                    # 음악 (mp3)
    └── images/                   # 이미지


[각 파일의 역할]

HTML  = 무엇이 있는가  (제목, 버튼, 박스 등 구성 요소)
CSS   = 어떻게 보이는가 (색, 크기, 위치)
JS    = 어떻게 움직이는가 (재생, 일시정지, 재생 바 등)
JSON  = 데이터 (곡 목록)


[규칙]
1. 새 기능(화면 조각)을 만들면 components/기능이름/ 폴더를 만들고,
   그 안에 기능이름.html / 기능이름.css / 기능이름.js 를 둔다.
   폴더 이름과 파일 이름은 반드시 같아야 한다.
   예) 갤러리 -> components/gallery/gallery.html, gallery.css, gallery.js
2. 새 페이지는 pages/페이지이름/페이지이름.html 로 만든다. (아래 [페이지 추가하는 법] 참고)
3. 여러 기능이 함께 쓰는 CSS 는 css/ 에, 사이트 전체 핵심 JS 는 js/core/ 에 둔다.
4. 데이터(곡 목록 등)는 data/, 음악은 assets/audio, 이미지는 assets/images 에 넣는다.
5. 파일 이름은 영문 소문자와 하이픈(-) 또는 언더스코어(_)로 짓는다.
   한글과 공백은 피한다. (화면에 보이는 제목은 playlist.json의 title에 한글 가능)
6. 컴포넌트/페이지의 .html 파일은 맨 마지막 줄에 </body> 를 넣는다.
   (Live Server 오류 방지. 자세한 이유는 js/core/component-loader.js 주석 참고)
7. 컴포넌트는 index.html 에 슬롯 한 줄만 추가하면 연결된다. (아래 [컴포넌트 추가하는 법] 참고)
   css/js 파일을 index.html 에 따로 연결하지 않는다.


[크기·색상 바꾸는 법 (하드코딩 금지)]
- 여백, 버튼 크기, 글자 크기, 색상은 css/base.css 맨 위의 :root 변수에서만 바꾼다.
  예) --edge (화면 가장자리 여백), --btn-size (버튼 크기), --panel-width (박스 너비)
- 다른 css 파일에서는 숫자나 색상을 직접 쓰지 않고 var(--변수이름)으로 가져다 쓴다.
- 크기 단위는 px 대신 rem, vw, %, clamp(), min() 등을 사용한다.
  (화면 크기와 글자 크기 설정에 맞춰 자동으로 조절되도록)
- 각 요소는 화면 가장자리 기준으로 배치하고 (fixed + 여백 변수), 좁은 화면에서
  서로 겹치지 않도록 너비를 계산식(min, calc)으로 제한한다.


[컴포넌트 추가하는 법] (js/core/component-loader.js)
1. components/기능이름/ 폴더를 만들고 기능이름.html / .css / .js 세 파일을 넣는다.
2. index.html 에서 원하는 위치에 한 줄을 추가한다.
   <div data-component="기능이름"></div>
3. 로더가 이 자리를 components/기능이름/ 의 내용으로 자동으로 채운다.
   순서: CSS 와 HTML 을 함께 불러옴 -> HTML 삽입 -> JS 실행
4. 컴포넌트끼리는 서로 기다리지 않고 동시에 불러온다.
   하나가 실패해도 나머지는 계속 진행한다. (오류는 콘솔에 표시)
5. 현재 슬롯: music-player(왼쪽 아래), site-menu(오른쪽 아래), shooting-stars(배경)


[페이지 추가하는 법] (js/core/page-router.js)
1. pages/페이지이름/페이지이름.html 을 만들고 내용을 쓴다. 맨 끝에 </body> 한 줄을 넣는다.
2. 주소 끝에 #페이지이름 을 붙여서 확인한다. 예) .../index.html#about
3. 링크를 걸 때는 <a href="#페이지이름"> 으로 쓴다. index.html 은 고칠 필요가 없다.
4. 주소에 #이 없으면 home 을 보여주고, 없는 이름이면 home 으로 돌아간다.
5. 페이지를 바꿔도 index.html 은 다시 불러오지 않는다.
   그래서 음악 플레이어, 메뉴, 별똥별이 그대로 유지되고 음악이 끊기지 않는다.
6. 페이지 안의 내용은 <main id="page-view"> 안에 들어간다.


[곡 추가 방법]
1. mp3 파일을 assets/audio/ 에 넣는다.
2. data/playlist.json 에 한 줄을 추가한다.
   - 곡과 곡 사이에는 쉼표(,)를 넣는다.
   - 마지막 곡 뒤에는 쉼표를 넣지 않는다.
   - artist(가수)는 생략할 수 있다. 없으면 빈 칸으로 표시된다.

예)
[
  { "src": "assets/audio/first_song.mp3",  "title": "첫 번째 곡",  "artist": "가수 이름" },
  { "src": "assets/audio/second_song.mp3", "title": "두 번째 곡" }
]

[애니메이션 사용법] (css/animations.css)
원하는 요소의 class에 이름을 추가한다.

  이름              효과                    기본 방향
  anim-float-in     부드럽게 떠오르기       아래에서 위로
  anim-scale-in     살짝 커지며 나타나기    (방향 없음)
  anim-slide-in     슬라이드                위에서 아래로

  anim-float-out    떠오르며 사라지기       아래로
  anim-scale-out    작아지며 사라지기       (방향 없음)
  anim-slide-out    슬라이드로 사라지기     위로
  (-out은 사라진 뒤에도 투명 상태 유지. 방향은 to-top / to-bottom / to-left / to-right)

  anim-spin         계속 회전 (LP판)        (방향 없음, 한 바퀴 시간은 --spin-duration)

방향 클래스 (float, slide에 함께 추가): from-top / from-bottom / from-left / from-right
  예) <div class="anim-slide-in from-bottom">   (아래에서 올라옴)

속도, 지연, 거리는 css/base.css 맨 위 변수에서 바꾼다.
한 요소만 바꾸려면 style을 쓴다.
  예) <div class="anim-float-in" style="--anim-duration: 1s; --anim-delay: 0.2s">

새 애니메이션은 animations.css에 anim-이름 으로 추가하고 이 목록에도 적는다.


[열고 닫는 UI는 ".visible" 토글 방식] (예: 사이트 메뉴 패널)
- 반복해서 열고 닫는 요소(패널, 메뉴, 팝업)는 transition + ".visible" 클래스로 만든다.
  기본 상태 = 닫힘(opacity 0, visibility hidden, pointer-events none)
  .visible  = 열림 (JS가 클래스를 붙였다 뗌)
- hidden 속성 / display:none 은 transition이 안 되므로 쓰지 않는다.
- 처음 한 번만 나타나는 요소는 animations.css 의 anim-○○-in 클래스를 쓴다.
- 짧은 전환 시간은 base.css 의 --anim-duration-fast 를 쓴다.


[음악 플레이어 상태 클래스] (#player 에 JS가 붙였다 뗌)
- .expanded    펼침 (위쪽 LP판 클릭으로 펼침 / 곡 정보 줄 클릭 또는 Esc 로 접음)
- .is-playing  재생 중. 없으면 LP판 회전이 멈춤 (animation-play-state: paused)
- .volume-open 볼륨 바 열림. 펼친 상태에서만 의미가 있고, 접으면 자동으로 닫힘

- 목록(.list-open)이 열려 있을 때 볼륨 바를 열면, 볼륨 바가 목록의 한 줄(--volume-h = --list-item-h) 자리를 차지해 목록이 4줄 → 3줄이 되고 카드 높이는 그대로다.
- 제목이 영역보다 길면(펼친 상태) 5초 쉬고 → 왼쪽으로 한 바퀴 흐르고 → 정지 → 반복.
  원본+복제본을 이어 붙여 끊김 없이 보이게 한다. 대기 시간/속도는 components/music-player/music-player.js 의 MARQUEE_DELAY_MS, MARQUEE_SPEED.
- 맨 왼쪽 버튼 = 노래 목록 버튼 (누르면 목록이 열림), 맨 오른쪽 버튼 = 볼륨 바 열기/닫기
- 볼륨은 localStorage "volume" 에 저장 (기본 20%)
