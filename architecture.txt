==============================================
 사이트 구조 (architecture)
==============================================

[폴더 구조]

my-site/
├── index.html          메인 페이지. 화면에 보이는 뼈대(HTML)
├── playlist.json       음악 곡 목록 (경로 + 제목)
├── architecture.txt    이 문서
├── animation-demo.html 애니메이션 미리보기 (사이트와 무관, 확인용)
├── .gitattributes      Git 설정 파일
├── css/                디자인(스타일) 파일
│   ├── base.css            사이트 전체 공통 스타일
│   ├── music-player.css    음악 플레이어 전용 스타일
│   ├── settings-menu.css   설정 메뉴 전용 스타일
│   └── animations.css      재사용 애니메이션 모음
├── js/                 동작(기능) 파일
│   ├── music-player.js     음악 플레이어 기능
│   └── settings-menu.js    설정 메뉴 기능 (현재: 볼륨)
└── assets/             음악, 이미지 같은 자료 파일
    ├── audio/              음악 (mp3)
    └── images/             이미지


[각 파일의 역할]

HTML  = 무엇이 있는가  (제목, 버튼, 박스 등 구성 요소)
CSS   = 어떻게 보이는가 (색, 크기, 위치)
JS    = 어떻게 움직이는가 (재생, 일시정지, 재생 바 등)
JSON  = 데이터 (곡 목록)


[규칙]

1. 새 기능을 만들면 기능 이름으로 파일을 나눈다.
   예) 갤러리 -> css/gallery.css, js/gallery.js
2. HTML 조각(플레이어 박스 등)은 따로 파일로 나누지 않고 index.html 안에 둔다.
3. 새 파일은 종류에 맞는 폴더에 넣는다.
   음악 -> assets/audio, 이미지 -> assets/images
4. 파일 이름은 영문 소문자와 하이픈(-) 또는 언더스코어(_)로 짓는다.
   한글과 공백은 피한다. (화면에 보이는 제목은 playlist.json의 title에 한글 가능)
5. 새 css/js 파일을 만들면 index.html에 연결해야 동작한다.
   - CSS: <head> 안에 <link rel="stylesheet" href="css/파일.css">
   - JS : </body> 바로 위에 <script src="js/파일.js"></script>


[크기·색상 바꾸는 법 (하드코딩 금지)]

- 여백, 버튼 크기, 글자 크기, 색상은 css/base.css 맨 위의 :root 변수에서만 바꾼다.
  예) --edge (화면 가장자리 여백), --btn-size (버튼 크기), --panel-width (박스 너비)
- 다른 css 파일에서는 숫자나 색상을 직접 쓰지 않고 var(--변수이름)으로 가져다 쓴다.
- 크기 단위는 px 대신 rem, vw, %, clamp(), min() 등을 사용한다.
  (화면 크기와 글자 크기 설정에 맞춰 자동으로 조절되도록)
- 각 요소는 화면 가장자리 기준으로 배치하고 (fixed + 여백 변수), 좁은 화면에서
  서로 겹치지 않도록 너비를 계산식(min, calc)으로 제한한다.


[곡 추가 방법]

1. mp3 파일을 assets/audio/ 에 넣는다.
2. playlist.json에 한 줄을 추가한다.
   - 곡과 곡 사이에는 쉼표(,)를 넣는다.
   - 마지막 곡 뒤에는 쉼표를 넣지 않는다.

예)
[
  { "src": "assets/audio/first_song.mp3",  "title": "첫 번째 곡" },
  { "src": "assets/audio/second_song.mp3", "title": "두 번째 곡" }
]

[애니메이션 사용법] (css/animations.css)

원하는 요소의 class에 이름을 추가한다. (미리보기: animation-demo.html)

  이름              효과                    기본 방향
  anim-float-in     부드럽게 떠오르기       아래에서 위로
  anim-scale-in     살짝 커지며 나타나기    (방향 없음)
  anim-slide-in     슬라이드                위에서 아래로

  anim-float-out    떠오르며 사라지기       아래로
  anim-scale-out    작아지며 사라지기       (방향 없음)
  anim-slide-out    슬라이드로 사라지기     위로
  (-out은 사라진 뒤에도 투명 상태 유지. 방향은 to-top / to-bottom / to-left / to-right)

방향 클래스 (float, slide에 함께 추가): from-top / from-bottom / from-left / from-right
  예) <div class="anim-slide-in from-bottom">   (아래에서 올라옴)

속도, 지연, 거리는 css/base.css 맨 위 변수에서 바꾼다.
한 요소만 바꾸려면 style을 쓴다.
  예) <div class="anim-float-in" style="--anim-duration: 1s; --anim-delay: 0.2s">

새 애니메이션은 animations.css에 anim-이름 으로 추가하고 이 목록에도 적는다.


[열고 닫는 UI는 ".visible" 토글 방식] (예: 설정 패널)

- 반복해서 열고 닫는 요소(패널, 메뉴, 팝업)는 transition + ".visible" 클래스로 만든다.
  기본 상태 = 닫힘(opacity 0, visibility hidden, pointer-events none)
  .visible  = 열림 (JS가 클래스를 붙였다 뗌)
- hidden 속성 / display:none 은 transition이 안 되므로 쓰지 않는다.
- 처음 한 번만 나타나는 요소는 animations.css 의 anim-○○-in 클래스를 쓴다.
- 짧은 전환 시간은 base.css 의 --anim-duration-fast 를 쓴다.


[음악 플레이어 상태 클래스] (#player 에 JS가 붙였다 뗌)
- .expanded    펼침 (위쪽 LP판 클릭으로 펼침 / 곡 정보 줄 클릭 또는 Esc 로 접음)
- .is-playing  재생 중. 없으면 LP판 회전이 멈춤 (animation-play-state: paused)
- .volume-open 볼륨 바 열림. 펼친 상태에서만 의미가 있고, 접으면 자동으로 닫힘

- 제목이 영역보다 길면(펼친 상태) 5초 쉬고 → 왼쪽으로 한 바퀴 흐르고 → 정지 → 반복.
  원본+복제본을 이어 붙여 끊김 없이 보이게 한다. 대기 시간/속도는 music-player.js 맨 위 상수.
- 맨 왼쪽 버튼 = 노래 메뉴 (아직 기능 없음), 맨 오른쪽 버튼 = 볼륨 바 열기/닫기
- 볼륨은 localStorage "volume" 에 저장 (기본 20%)
